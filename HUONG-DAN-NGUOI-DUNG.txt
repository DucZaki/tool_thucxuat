THỰC XUẤT TOOL — Hướng dẫn dùng
================================

CÀI BẰNG BỘ CÀI (cách nhanh nhất)
---------------------------------
1. Chạy ThucXuatTool-Setup.exe.
   (Windows có thể hiện SmartScreen: bấm "More info" → "Run anyway".)
2. Bộ cài tự làm hết, không cần bấm gì:
     - chép app vào %LOCALAPPDATA%\Programs\ThucXuatTool
     - tạo lối tắt «Thực Xuất» ở Desktop và Start Menu
3. Cài xong bấm «Mở ứng dụng». Lần sau mở bằng lối tắt «Thực Xuất».

App cần mạng để đọc ảnh. Chạy lại Setup.exe = cập nhật bản mới,
file config.json và thư mục KetQua vẫn giữ nguyên.

CÁCH CÀI BẰNG FILE ZIP (nếu không dùng bộ cài)
----------------------------------------------
1. Giải nén file zip ra 1 folder riêng (không chạy trong .zip).
2. Trong folder phải có ĐỦ 2 thứ cạnh nhau:
      ThucXuatTool.exe
      _internal\          ← folder này BẮT BUỘC, không được xóa/bỏ sót
3. Double-click: ThucXuatTool.exe
   (hoặc Chay-ThucXuatTool.vbs — mở app không nhấp nháy cửa sổ đen)

SAI → lỗi "Failed to load Python DLL ... _internal\python312.dll":
  - Chỉ copy mỗi file .exe sang Desktop / Zalo → THIẾU _internal
  - Phải copy CẢ folder sau khi giải nén

Nếu đã có đủ _internal mà vẫn lỗi DLL:
  Cài Microsoft Visual C++ Redistributable 2015-2022 (x64):
  https://aka.ms/vs/17/release/vc_redist.x64.exe
  Rồi mở lại app.

ĐỌC ẢNH QUA NVIDIA NIM
----------------------
Tạo API key tại https://build.nvidia.com/ rồi dán vào ô «API key NVIDIA».
Chọn «Tự động · Super VL → Nano Omni» hoặc chọn một model trong danh sách.
Ô nhập chỉ giữ key đến khi tắt app. App nhớ model đã chọn.
Khi bấm «Đọc phiếu và xuất Excel», ảnh đã tiền xử lý được gửi tới NVIDIA NIM.

THỰC XUẤT
---------
1. Thêm Excel gốc (DanhSachChiTietDatHangNhap_*.xlsx)
   — có thể thêm nhiều phiếu.
2. Bấm «Thêm ảnh…» để chọn tất cả ảnh. App tự xác định ảnh thuộc phiếu nào.
   App chỉ đọc cột Thực xuất. Nội dung cột Ghi chú không dùng để tính số lượng.
   Bấm «Xóa tất cả ảnh» nếu muốn bỏ nhanh toàn bộ ảnh khỏi danh sách
   (chỉ bỏ trong app, không xóa file trên máy).
3. Bấm «Đọc phiếu và xuất Excel»
   Nếu còn ảnh lỗi, bấm lại nút này để đọc tiếp; app giữ kết quả ảnh đã đọc
   và các dòng đã sửa tay trong phiên đang mở.
4. Kết quả: PDNxxxxx_MaSanPham_ThucXuat.xlsx trong thư mục «KetQua»
   (nằm cạnh ThucXuatTool.exe).
   Bấm «Mở thư mục xuất» để mở thư mục này trong Explorer.
5. Xem bảng «Kết quả»: nháy đúp 1 dòng để sửa ô «Đọc từ ảnh»
   nếu AI đọc sai — app tự lưu lại file Excel.
   Dòng chữ xám = bị bỏ (X / ô trống).

SỬA FILE ĐÃ XUẤT (kể cả file của lần chạy trước)
-----------------------------------------------
1. Chọn một file của phiếu đang mở, hoặc dùng «Chọn file khác...».
2. File hiện ngay trong bảng «3. Kết quả».
3. Nháy đúp một dòng, nhập số hoặc phép tính (3*8, 10+2, 12/3)
   rồi nhấn Enter để tính và lưu. Nhập X hoặc để trống để bỏ dòng.
4. Dùng «Lưu bản sao...» nếu muốn lưu dưới tên mới.
Có thể sửa file cũ mà không cần ảnh hay đọc lại AI.

FILE XUẤT RA
------------
File kết quả mặc định có 2 cột «Mã hàng» và «Số lượng chuyển» trong bảng Excel.
Số lượng là dữ liệu số. Excel hiển thị số nguyên và số thập phân theo thiết lập vùng.

KIỂM KÊ
-------
1. Mở tab «Kiểm kê». App nạp sẵn danh mục và mẫu nhập hàng.
   Dùng «Chọn Excel…» nếu cần thay danh mục hoặc mẫu.
2. Thêm ảnh rồi bấm «Đọc ảnh và đối chiếu».
3. Nếu cần sửa, chọn dòng, chọn mã và đơn vị trong danh sách, nhập số lượng rồi xác nhận.
4. Bấm «Xuất file nhập hàng». App dùng Giá vốn theo mặc định.

XUẤT LẠI FILE KẾT QUẢ
----------------------
Đã chạy xong rồi muốn làm mới file (vd sau khi sửa tay nhiều dòng):
bấm «Xuất lại file kết quả» — app xuất lại từ kết quả đã có, không đọc lại ảnh.

CẬP NHẬT PHẦN MỀM
------------------
- Mở app: app tự kiểm tra bản mới (cần mạng).
  Không có mạng thì app vẫn chạy bình thường.
- Có bản mới: nút «Cập nhật lên v...» hiện ở hàng tuỳ chọn.
  Bấm -> app tự tải (có %), thay thế rồi mở lại bản mới.
- File kết quả trong thư mục KetQua và config.json KHÔNG bị mất.
- Muốn kiểm tra tay: bấm nút «Kiểm tra cập nhật».

CÁCH TÍNH SỐ LƯỢNG
------------------
- Ghi X                  -> bỏ dòng
- Ghi Y (nét gạch chéo bị đọc nhầm) -> bỏ dòng (phiếu không có chữ Y)
- Ghi 3T*3               -> 9   (có dấu nhân thì nhân)
- Ghi 5T x 24            -> 120 (dấu x cũng là nhân)
- Ghi 10T, 4T, 1T        -> 10, 4, 1 (bỏ chữ, giữ nguyên số)
- Ghi 30cm, 10 gói, 30kg -> 30, 10, 30 (bỏ đơn vị, giữ nguyên số)
- AI đọc nét giống ✓     -> coi là X, bỏ dòng
KHÔNG nhân theo ĐVT: ĐVT «thùng 20 hộp» + ghi 10T vẫn là 10 thùng -> xuất 10.
Chỉ nhân khi ô viết tay có dấu nhân (vd 5T x 24 -> 120).
Cột ĐVT trong bảng Kết quả giúp bạn đối chiếu trước khi nhập KiotViet.

Lưu ý:
- Model 4b đọc khoảng 80–90% số dòng; luôn kiểm tra bảng Kết quả.
- Windows cảnh báo «Unknown publisher» → More info → Run anyway.

Hỗ trợ: liên hệ người gửi bản cài.
